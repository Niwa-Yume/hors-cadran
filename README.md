# Hors Cadran — Everything but the watch

Single-page, front-end-only shop for an independent Geneva reseller of watch-house goodies
(cards, caps, leather, valet trays, boxes, press kits). No watches. No backend, no auth, no payment.

Astro (static output) · TypeScript strict · Tailwind v4 · GSAP (ScrollTrigger, SplitText, Flip, CustomEase) ·
Lenis · three.js (vanilla, lazy) · nanostores (cart persisted to `localStorage`).

## Run

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # astro check + static build into dist/
npm run preview  # serve dist/ locally
```

Requires Node ≥ 22.12. Astro is pinned to 6.x because Astro 7 requires Node ≥ 22.22; on a newer Node
you can `npm install astro@latest` (Vite is pinned to 7.x to match Astro 6's bundled Vite).

## Deploy (free tier)

`dist/` is plain static files.

- **Vercel**: framework preset “Astro”, build `npm run build`, output `dist`.
- **Cloudflare Pages**: build `npm run build`, output `dist`.
- **Netlify**: build `npm run build`, publish `dist`.

## Where to change things

| What | Where |
| --- | --- |
| Brand name (nav, preloader, footer wordmark, title, dial centre) | `src/data/brand.ts` → `BRAND_NAME` |
| Tagline, contact lines, legal line | `src/data/brand.ts` |
| Products, categories, accents, hero drops, featured cards, spec-sheet object | `src/data/products.ts` (**SAMPLE DATA**) |
| Images | `public/images/{products,drops,macro}/` |
| Design tokens (colours, fonts, radii, easings), glass, grain, pill buttons | `src/styles/global.css` |

### Images

The current images are neutral SVG placeholders (object on paper / studio backdrop), generated by
`node tools/generate-placeholders.mjs`. To use photography, drop files in `public/images/…` and update
`images` / `image` in `src/data/products.ts`. Product images work best as cut-outs on a transparent
background (tiles add the paper colour). Hero drop images are 16:10; they are also drawn into the
WebGL scene, so keep them same-origin.

Maison names appear only as factual product descriptions. Never use maison logos or trademarks as UI branding.

## Structure

```
src/
  data/            brand.ts, products.ts (sample data)
  styles/          global.css — tokens (@theme), type roles, glass, grain, pills, spec table
  components/ui/   PillButton, Marquee, Cursor, Toast, CartDrawer, QuickView
  components/sections/
                   Preloader, Nav, HeroFrame, MarqueeBand, TheTick, TheDial,
                   Shop, SpecSheet, Watching, ShipsWorldwide, Footer
  scripts/         gsap.ts, lenis.ts, env.ts, events.ts, cursor.ts, reveal.ts, cart.ts,
                   dialog.ts, spec.ts, ui.ts
  scripts/three/   bezel-geometry.ts, hero-scene.ts, footer-scene.ts, shared.ts
  pages/index.astro
public/images/
tools/generate-placeholders.mjs
```

Sections talk through window events (`src/scripts/events.ts`): `hc:drop`, `hc:filter`, `hc:quickview`,
`hc:cart-open`, `hc:toast`, `hc:preloaded`. Any element with `data-add="<id>"`, `data-quickview="<id>"`
or `data-cart-open` works anywhere on the page.

## Behaviour notes

- **Preloader** plays once per browser session (`sessionStorage['hc-preloaded']`); click or Escape skips it.
- **Hero bezel** (three.js) loads on `requestIdleCallback` after the preloader, only ≥ 768px with WebGL.
  The drop image is rendered inside the scene so the glass refracts it; the DOM `<img>` stays as the LCP
  and fallback until the scene is ready. Rendering pauses off-screen and in hidden tabs; DPR capped at 1.75.
- **Footer bezel** gets its own canvas, created when the footer approaches the viewport.
- **Reduced motion**: no Lenis, no preloader, no auto-advance or ticking (The Tick shows Prev/Next), no char
  reveals, static 3D frame.
- **Custom cursor** only with a fine pointer; native cursor hidden only while it runs.
- Glass panels that hold body text (cart drawer, toast) use a tinted variant of the glass recipe so text stays legible over any section.
